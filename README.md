# aatikm-skill-factory

A collection of skill files, templates, and checklists to help a tech lead increase day-to-day productivity.

## Structure

| Directory | Purpose |
|-----------|---------|
| [`skills/code-review/`](skills/code-review/) | Code review guidelines and pull request checklist |
| [`skills/architecture/`](skills/architecture/) | Architecture Decision Record (ADR) template |
| [`skills/team-management/`](skills/team-management/) | 1:1 agenda, onboarding checklist, and performance review template |
| [`skills/project-management/`](skills/project-management/) | Sprint planning, retrospective, and daily stand-up templates |
| [`skills/incident-response/`](skills/incident-response/) | Incident runbook and post-mortem template |
| [`skills/technical-writing/`](skills/technical-writing/) | RFC and documentation page templates |

## How to use

1. Browse the relevant directory for the skill you need.
2. Copy the template or checklist into your own notes, wiki, or project docs.
3. Fill in the placeholders (marked with `<angle brackets>`) with real information.
4. Iterate and customise each file to match your team's conventions.
