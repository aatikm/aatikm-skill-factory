---

## Before day 1 (manager / HR)

- [ ] Laptop ordered and configured
- [ ] Accounts created: email, Slack, GitHub, Jira/Linear, cloud console, VPN
- [ ] Calendar invites sent: first-week 1:1s, team ceremonies, skip-level intro
- [ ] Buddy assigned and briefed
- [ ] First-day schedule emailed to new hire

---

## Day 1 — Welcome

- [ ] Welcome intro with manager
- [ ] Office / remote setup tour
- [ ] Team introductions (async message or live meeting)
- [ ] Walk through the team's communication norms (Slack etiquette, async vs sync)
- [ ] Walk through the company handbook / policies
- [ ] Confirm all accounts work

---

## Week 1 — Orientation

### Engineering environment
- [ ] Dev environment setup guide followed (`README` or wiki link: <link>)
- [ ] Can run the project locally
- [ ] Can run the full test suite locally
- [ ] CI/CD pipeline explained
- [ ] Deployment process explained
- [ ] Monitoring / alerting dashboards shown

### Codebase walkthrough
- [ ] High-level architecture overview (diagram or ADR)
- [ ] Key services / repositories identified
- [ ] Data model overview
- [ ] Coding standards and style guide reviewed
- [ ] Code review process explained (see `skills/code-review/guidelines.md`)

### Team processes
- [ ] Agile / sprint process explained
- [ ] Definition of Done reviewed
- [ ] On-call rotation explained (if applicable)
- [ ] Incident response process explained

---

## Week 2 — First contribution

- [ ] First ticket assigned (small, well-scoped bug or chore)
- [ ] First pull request opened
- [ ] Participated in at least one code review as reviewer
- [ ] Attended and contributed to stand-up / planning

---

## Week 3–4 — Building confidence

- [ ] Completed 2–3 tickets independently
- [ ] Delivered a short knowledge-share or demo to the team
- [ ] 30-day retrospective 1:1 with manager:
  - What's going well?
  - What's confusing or unclear?
  - What support do you need?

---

## 90-day milestone

- [ ] Owning a small feature end-to-end
- [ ] Contributing to sprint planning and estimation
- [ ] 90-day review completed with growth goals set
