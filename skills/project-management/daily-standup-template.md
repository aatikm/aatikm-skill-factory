# Daily Stand-up Template

## Purpose

The daily stand-up is a *coordination* meeting, not a status report to the manager. The goal is for the team to identify blockers and dependencies so they can self-organise.

**Recommended duration:** 15 minutes  
**Format:** Synchronous (standup) or async (Slack / written)

---

## Synchronous format

Each team member answers three questions:

1. **What did I complete since the last stand-up?**
   > Focus on work *done* (merged, deployed, reviewed), not work *in progress*.

2. **What am I working on today?**
   > Link to the ticket. If you have multiple items, name the highest priority one first.

3. **Is anything blocking me?**
   > If yes, name the blocker and who can help. Do *not* try to solve it live — park it for after stand-up.

---

## Async format (Slack / written)

Use this template in the team's stand-up channel:

```
:done: *Done:* <what I completed>
:working_on_it: *Today:* <what I'm working on>
:blocker: *Blockers:* <blockers, or "none">
```

---

## Facilitation tips (for tech lead)

- Start on time. Latecomers catch up asynchronously.
- Keep answers brief — save discussions for after the meeting ("parking lot").
- Actively surface blockers: "Is there anything stopping the team from hitting the sprint goal?"
- Rotate the facilitator role across the team — it builds ownership.
- If stand-up consistently runs long, consider:
  - Limiting to 2-minute updates per person (use a timer)
  - Moving detailed discussions to a separate follow-up slot
  - Switching to async format for low-dependency days

---

## Anti-patterns to watch for

| Anti-pattern | What to do |
|-------------|-----------|
| Status report to the manager | Redirect: "Tell the *team*, not me." |
| Problem-solving during stand-up | "Let's park that — who should join after?" |
| Same blocker repeated daily | Follow up 1:1 after stand-up; remove the blocker |
| People joining unprepared | Encourage async prep the night before |
| Stand-up becomes a meeting | Enforce the 15-minute timebox; create a parking lot |
