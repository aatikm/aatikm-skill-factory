## Preparation (async, before the meeting)

Ask each team member to add sticky notes / comments to each category in the team's retro board (Miro, FigJam, Retrium, etc.):

- **Start** — Things we should begin doing
- **Stop** — Things we should stop doing
- **Continue** — Things that are working well and should keep going

---

## Agenda (60 min)

### 1. Set the stage (5 min)

Review the team agreement:
> *This is a blameless space. We assume everyone acted with the best intentions given the information they had at the time.*

### 2. Review previous action items (5 min)

| Action | Owner | Status |
|--------|-------|--------|
| | | ✅ Done / 🔄 In progress / ❌ Not done |

### 3. Gather data — dot voting (10 min)

Each person gets **5 votes** to allocate across the sticky notes (multi-vote allowed on a single item). Top-voted items are discussed first.

### 4. Generate insights (30 min)

Work through top-voted items. For each:
1. Discuss the root cause (use "5 Whys" if needed)
2. Identify whether it's systemic or one-off
3. Decide whether to create an action item
